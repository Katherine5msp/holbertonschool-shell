# I/O Redirections and Filters

- `0-hello_world`: Prints "Hello, World" followed by a new line to standard output.
- `1-confused_smiley`: Displays a confused smiley `"(Ôo)'`.
- `2-hellofile`: Displays the contents of `/etc/passwd`.
- `3-twofiles`: Displays the contents of `/etc/passwd` and `/etc/hosts`.
- `4-lastlines`: Displays the last 10 lines of `/etc/passwd`.
- `5-firstlines`: Displays the first 10 lines of `/etc/passwd`.
- `6-third_line`: Displays the third line of the file `iacta`.
- `7-file`: Creates a file with a special name containing `Best School` followed by a newline.
- `7-file`: Creates a file with a special name containing `Best School` followed by a newline.
- `8-cwd_state`: Writes the output of `ls -la` to `ls_cwd_content`, overwriting the file if it already exists.
